# 我的阅读记录工具

我的第一个 Python 项目：通过终端添加和查看阅读记录。
只使用 Python 自带功能，无需安装额外的库。

## 运行

需要 Python 3。在项目文件夹打开终端，运行：

```bash
python3 main.py
```

输入 `1` 添加书名和读后感，输入 `2` 查看记录，输入 `3` 退出。

## 使用示例

```text
我的阅读记录
1. 添加记录
2. 查看记录
3. 退出
请选择：1
书名：小王子
一句读后感：喜欢它对友谊的描写。
添加成功！
```

## 当前限制

记录只在本次运行中保留，退出程序后会消失。

## 读懂代码

- `records` 是一个列表，每条记录是包含书名和读后感的字典。
- `while True` 重复显示菜单；`break` 结束循环。
- `input()` 接收输入，`.strip()` 去掉两端空白。
- `enumerate()` 在遍历记录时生成编号。
- `main()` 将程序的主要流程放在一个函数中。
- `if __name__ == "__main__"` 让直接运行这个文件时才启动菜单。
- 最后的异常处理让按下 Ctrl+C 或结束输入时也能正常退出。
